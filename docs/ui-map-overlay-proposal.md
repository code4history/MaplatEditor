### 1.2 撮影の条件

- playwright の electron（既存の e2e と同じ隔離起動 `tests/e2e/helpers/launchIsolated.ts`、フィクスチャは `tests/fixtures/` の中の、データフォルダの移行の検証に使うもの）で、1440×900、日本語の UI で撮った。

  - 明るい地図: 既存のフィクスチャ（`tests/e2e/fixtures/fake-osm-tile.png` と `osm-tiles/`）。薄いベージュの格子。

### 3.4 OpenLayers の既定の部品と自作の部品のずれ

- OL の部品（#1〜#3）は「半透明の灰の帯に白い小さなボタン」、自作（#6〜#8）は Bootstrap の「白地＋1px の線＋薄い影」で、並ぶと別の部品に見える（MapEdit の右の地図で左上と右下を見比べると分かる）。
- OL と取り込みの部品の名前は英語のまま（`Zoom in`・`Reset rotation`・`Legend`）か、無い（住所検索・ホーム位置）。白背景の上の UI では aria-label を必須にしている（ui-grammar §2.1）のと揃っていない。
- 取っ手（#19・#23）と描画中の線（#25）は OL の既定の青で、自作の図形の赤と色の意味がつながっていない。

## 4. 決まりの案

### 4.1 役割の分け方（案 A・案 B に共通）

| 役割 | 何か | 今の該当 |
|---|---|---|
| 視点の道具 | 見る場所・大きさ・向きを変える | ズーム・回転のリセット・住所検索 |
| 表示の切り替え | 状態を持ち、押すと選べる | ベースマップの切り替え |
| 画面の道具 | その画面だけの操作を 1 回する | 推定・ホーム位置に設定 |
| 情報 | 押さない表示 | 帰属表示・凡例 |
| 浮かぶメニュー | 呼んだときだけ出る | 右クリックのメニュー・住所検索の候補・切り替えのパネル |
| 編集中の図形 | 利用者が動かす・描く線と点、その取っ手 | 外郭・対応線・範囲の矩形・ホーム位置の点・POI のピン・取っ手 |
| 参考の図形 | 動かさない線・面 | TIN の網・存在範囲・アプリ対象範囲・絞り込み範囲（自動）の矩形 |

### 4.2 案 A: 白い札にそろえる（推奨）

地図の上の部品を、OL の既定のものも含めて「不透明の白地＋濃い縁＋影」の札にそろえる。

| 役割 | 形 | 配置 |
|---|---|---|
| 視点の道具 | 32×32 の札。地 `#fff`、縁 1px `rgba(0,0,0,.45)`、影 `0 1px 4px rgba(0,0,0,.35)`、角丸 4px、Bootstrap Icons（＋・−・方位・虫めがね）。縦に並ぶものは 1 枚の札にまとめる | 左上。上からズーム → 回転のリセット → 住所検索 |
| 表示の切り替え | 同じ札。今の選択の名前を札に出す（例「OpenStreetMap ▾」）。開くのはクリックで、パネルは浮かぶメニューの形 | 右上。全部の地図で同じ部品にする。小窓にも置く |
| 画面の道具 | 同じ札・32×32・アイコン。aria-label と title を必ず付ける（i18n） | 右下。帰属表示の上 |
| 情報 | 地 `rgba(255,255,255,.85)`、縁なし、文字 12px `#333`。凡例は色の見本と名前 | 帰属は右下の最下段。凡例は左下 |
| 浮かぶメニュー | Bootstrap の `dropdown-menu` と同じ見た目（白・縁・影・角丸） | 呼んだ所 |
| 編集中の図形 | 色の線の外側に白の縁取り 1.5px（halo）、さらに外に濃い灰 `#555` の細線。点は不透明にする。取っ手も同じ色にそろえる | — |
| 参考の図形 | 線を 1.5px 以上にし、白の縁取りを付ける。塗りは今のまま薄く | — |

決めてしまうこと（機械で決まる理由つき）:

- 札の地は不透明にする。半透明は地図の色に染まり、§3.2 のとおり明るい地図で縁が消える。縁は `rgba(0,0,0,.45)` で、明るい地図の地 `#f2efe9` に対し 3.28:1 になる（`.3` では 2.09:1 で足りない）。暗い地図では白地そのものが 10:1 を超える。
- 大きさは 32px にする。OL の 22px は WCAG 2.2 の 2.5.8（24px）に届かない。今の自作のボタン（32×31）に合わせる。
- 線・点は 2 色の縁取りにする。3 つの背景のどれでも、白（暗い地図で 10.94:1）か濃い灰 `#555`（明るい地図で 6.50:1、茶色の地図で 3.05:1）のどちらかが 3:1 を超える。色そのものは変えなくても見分けられる。
- 名前の無い部品を無くす。OL の部品は `controlDefaults` のオプション（`zoomInTipLabel` など）で i18n の文言を渡す。
- 帰属表示は全部の地図で出す。出ないのは地図の出典の表示漏れなので、見た目の好みではない。
- 実装は CSS 1 か所（`src/assets/scss/` に地図の上の部品の scss を足し、`main.scss` で OL の CSS の後に読む）で OL・取り込みの部品の見た目を上書きする。自作の部品は共通の class（例 `map-tool`）を使う。

利点: どの背景でも縁と印が読める。自作と OL の部品が同じ部品に見える。CSS 1 か所と class 1 つなので、検査器（ui-grammar §9）に「地図の上の `button` は `map-tool` を持ち aria-label がある」という規則を足せる。

欠点: OL の既定の見た目から離れるので、OL を上げたときに CSS の追従が要る。札が大きく（22px → 32px）、白いので地図を隠す面積が増える。2 色の縁取りは図形の数が多いと描画が少し重くなる（GCP が数百点のとき。計測していない）。

### 4.3 案 B: OL の既定に寄せる（最小の変更）

自作の部品を OL の見た目（半透明の灰の帯に白い小さなボタン）に寄せ、ベースマップの切り替えは `ol-layerswitcher` にそろえる。図形は色を変えず、線を太くするだけ。

利点: 変更が小さい。OL を使う他の地図サイトと見た目が近い。CSS の上書きが少なく、OL を上げても崩れにくい。

欠点: §3.2 の「明るい地図で縁が消える」は直らない（半透明の帯が地の色に染まる）。22px は 2.5.8 に届かない。`ol-layerswitcher` はアイコンだけで今の選択が見えず、マウスを乗せると開くので地図の右上を通るたびにパネルが開く。茶色の古地図の上の赤い線の問題は太さだけでは解けない。

### 4.4 どちらを推すか

案 A を推す。案 B は変更が小さいが、§3.2 の読めない所が残る。

## 6. 人間に決めてほしいこと（好み・感覚）

2026-11-13 にすべて決まった（1 は案 A、2〜4 は §4.2 の値のまま）。以下は決める前の記録。

1. **案 A と案 B のどちらにするか。** 写真で見比べたうえでの感覚で決めてほしい（推すのは案 A）。
2. **札の白さと影の強さ。** 案 A の値（地は不透明の白、影 35%）は「くっきり」寄り。地図を隠す感じが強ければ、影を弱める・札を少し透かす方向に振れる（透かすほど明るい地図で縁が消える）。
3. **編集中の図形の色。** 縁取りを付ければ赤のままでも見分けられるが、茶色の古地図の朱の線と色が近い。赤のままにするか、古地図に少ない色（例: 青紫・マゼンタ）へ変えるか。
4. **ベースマップの切り替えの見せ方。** 案 A は今の選択の名前を札に出す（場所を取るが一目で分かる）。アイコンだけ（場所を取らない）が好みならそうする。

## 7. 確かめていないこと

- 本物の OSM・地理院の地図・航空写真・茶色の古地図では撮っていない。背景は合成のタイルと既存のフィクスチャで代用した（§1.2）。
- AppEdit のプレビューの地図のタイルは写真では出なかった（iframe の中のビューアのタイルの差し替えが効かなかった。原因は調べていない）。プレビューの中の部品は Maplat UI（ビューア）のもので、Editor の決まりの対象外とした。ビューアの部品とそろえるかは別の検討になる。
- 地図を回した状態、GCP の取っ手をつかんだ状態、範囲の矩形を描いている途中、POI の選択中のピンは撮っていない（形はコードから書いた）。
- MapEdit・POI で帰属表示が出ない理由は調べていない（§5 の 8）。
- 縁取りを付けたときの描画の重さは計っていない。
- 画面の幅が狭いとき（MapEdit の左右の地図が細いとき）の部品の重なりは見ていない。
