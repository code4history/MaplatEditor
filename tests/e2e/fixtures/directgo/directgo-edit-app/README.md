# directgo（リンクの形）を画面で確かめるためのアプリ

`directgo-demo-pois.geojson` は、内容の形「リンク」の POI 3 つと「標準」の POI 1 つを持つ POI ソースです（東京駅の周り）。

| 表示 ID | 内容 | 押したときに見えるもの |
|---|---|---|
| `link-same-tab` | リンク: `https://example.org/` | 同じタブが外のページへ移る（情報窓は出ない） |
| `link-new-tab` | リンク: `https://example.org/`・新しいタブで開く | 別のタブで開き、地図の画面は残る |
| `link-in-app` | リンク: `#!s:gsi/x:15112600.5/y:4161951.6/z:15` | 同じアプリの中で「地理院地図」の京都駅付近へ移る |
| `standard` | 標準（説明だけ） | 情報窓が出る |

## 手順

1. Editor の POI ソースの一覧で、このファイルを取り込む（GeoJSON の取り込み）。
2. アプリを作り、地図に OpenStreetMap（`osm`）と 地理院地図（`gsi`）を入れ、POI に 1 の POI ソースを入れる。
   アプリの設定の「状態URL」はオンのまま（`#!s:` のリンクは、ビューアが状態 URL を読むときだけ動く）。
3. アプリを書き出し、zip を展開したフォルダを **http の静的サーバ**で配ってブラウザで開く
   （`file://` で開くと同じアプリの中のリンクは動かない）:

   ```bash
   cd <展開したフォルダ> && python3 -m http.server 8080 --bind 127.0.0.1
   # ブラウザで http://127.0.0.1:8080/ を開く（止めるときは Ctrl-C）
   ```

4. 4 つの POI を順に押し、上の表のとおりに見えることを確かめる。

## Editor の中で確かめること

- 「標準」の POI を「リンク」にすると、説明の欄が隠れて「データは残ります」の表示が出る。「標準」に戻すと確認の窓のあと、説明が元のまま見える（リンク先は消える）。
- リンク先に `javascript:alert(1)` を入れると理由が出て保存できない。`https://…` なら保存できる。
- Editor のプレビューではリンクは開かない（注記のとおり。書き出したアプリで確かめる）。

自動テスト: `tests/e2e/directgo-edit.spec.ts` の「確かめ用アプリ」が、このファイルを同じ形で書き出して directgo が入力のまま入ることを確かめる（環境変数 `DIRECTGO_DEMO_EXPORT_PATH` を付けると、その zip を指定の場所に置く）。
